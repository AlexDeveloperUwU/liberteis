# Config Service

This document explains the functions available in the `configService.js` file.

## Functions

### setConfig(key, value)
Adds a new configuration to the database.

### updateConfig(key, value)
Updates an existing configuration in the database.

### deleteConfig(key)
Deletes a configuration from the database.

### getConfig(key)
Retrieves a configuration from the database.

### getConfigs()
Retrieves all configurations from the database.

### checkConfigExistence(key)
Checks if a configuration exists in the database.
