# Functions available in _spacesController_

## Introduction

In this controller, you will find functions related to the application's space management.

These functions allow you to retrieve, save, update, and delete space data.
Additionally, the controller includes comprehensive validation to ensure that the data being saved or updated is valid, successfully structured, and of the appropriate data type.

## Functions available

- `addSpace`: saves the given space data in the database (see the data structure below)

- `getSpace`: retrieves the space data from the database based on the given space ID

- `getSpaces`: retrieves all space data from the database

- `getSpaceByName`: retrieves the space data from the database based on the given space name

- `updateSpace`: updates the space data in the database based on the given space ID

- `deleteSpace`: deletes the space data from the database based on the given space ID

- `checkSpaceExistence`: checks if the space exists in the database based on the given space ID
