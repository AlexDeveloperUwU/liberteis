# Functions available in _categoriesController_

## Introduction

In this controller, you will find functions related to the application's category management.

These functions allow you to retrieve, save, update, and delete category data.
Additionally, the controller includes comprehensive validation to ensure that the data being saved or updated is valid, successfully structured, and of the appropriate data type.

## Functions available

- `addCategory`: saves the given category data in the database (see the data structure below)

- `getCategory`: retrieves the category data from the database based on the given category ID

- `getCategories`: retrieves all category data from the database

- `getCategoryByName`: retrieves the category data from the database based on the given category name

- `updateCategory`: updates the category data in the database based on the given category ID

- `deleteCategory`: deletes the category data from the database based on the given category ID

- `checkCategoryExistence`: checks if the category exists in the database based on the given category ID
